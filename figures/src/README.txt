Figures for the JCDE manuscript (dual normalization).
Data: figdata.json, extracted from step3_all_runs.csv, step4_variant_runs.csv, step4_guard_analysis.csv and step6_runs.csv.
Run from this folder:  set FIG_OUT=..\  then  python fig1.py  (likewise fig2-fig7, ga.py)
Needs matplotlib, numpy, pandas and the Liberation Sans font (metric-compatible with Arial).
Submission files: fig_N.pdf/.png/.tif; multi-panel figures as fig_N_A, fig_N_B (no panel labels inside, per JCDE checklist 6.7).
preview/fig_N.png: panels combined with (A)/(B) below each, for the draft only.
